已知限制：

- 在 Wayland 上，便签可能没法一直留在最前面。窗口里会说明这一点。
- macOS 安装包未签名。本机不能生成 macOS 或 Linux 安装包。
- 提醒只在程序还开着的时候发出。关掉程序之后，到点不会响。
- `@` 随这一版交付。它复用笔记里的 `/` 菜单，邮箱中间的 `@` 不打开。
- 小功能目前跑在应用内的沙箱页面，不是单独进程。

Windows x64 安装包是 marktext-win-x64-7.17.0-setup.exe。macOS 和 Linux 安装包没有生成。

# 7.2.0

小版本。待办和日历还是同一批任务，只是看得更清楚，也更能从一边走到另一边。

上一版是 7.1.0。分叉基线仍然是上游 MarkText v0.20.0。

参考的是两套做法，没有照搬代码。Logseq 的文件版把日期留在原来那一行，日记只是这一天的笔记，不把任务再抄一份。Obsidian Tasks 把未完成的事分成逾期、今天、未来、无日期，点一条回到原文。周视图和时间栅格仍然不做。

这次改了：

- 日历左边是月历，有星期，有今天。有待办的日期有一个点，逾期的点用删除色。
- 右边可以看这一天，也可以按逾期、今天、未来 7 天、更晚、无日期看。数字是这一档还有多少条。
- 每一条带上所在笔记、高或低优先级、重复。勾选会写回原来那一行。点文字回到原来那一行，并带上这条的属性。
- 在某一天新建，仍然写进这一天的笔记，写完留在日历里，方便连续加。
- 可以打开这一天的笔记。还没有这个文件时，只建一篇空笔记，不额外造一条待办。
- 侧栏的待办用同一套分组，不再把 7 天内和更晚混成一档。
- 十二种语言都写了这些句子。

没有做安装包。核心测试 19 条通过。

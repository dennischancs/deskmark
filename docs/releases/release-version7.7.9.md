# 7.7.9

修订。安装后的程序也能找到托盘图标。关掉主窗口时，有托盘就不会退出。

上一版是 7.7.8。分叉基线仍然是上游 MarkText v0.20.0。

图标打在 `resources/static` 里。7.7.8 只在当前工作目录的 `static` 里找，安装后找不到，托盘没有建起来，关掉主窗口就退出了。现在先找安装目录里的图标，开发运行再退回工作目录。

Windows 安装包是 dist/marktext-win-x64-7.7.9-setup.exe。解包程序文件版本是 7.7.9。直接打开解包后的程序可以启动。开始菜单里的「Deskmark」指向这个程序，并带有应用编号。macOS 和 Linux 的安装包没有生成。

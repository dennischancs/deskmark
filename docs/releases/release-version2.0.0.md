# 2.0.0

大版本。阶段 2 的笔记索引落地。索引可以删掉重建，写到一半关掉也不会留下半截数据。

上一版是 1.0.0。笔记格式没有变。

这次做了：

- `.deskmark/index.sqlite` 记下笔记和待办。表里有笔记路径、任务、截止日期和提醒。
- 全量重建的结果只由文件内容决定，顺序稳定。
- 只改一篇时，其他笔记的任务不动。
- 一篇的信息读不出来时，其他笔记照常进索引。这篇会标成信息无法读取，正文里的待办仍然在。
- 编辑器里还有未保存的修改时，外部改动不会写进索引。
- 同一个笔记文件夹同时只允许一个写入者。上次异常退出留下的锁可以接手。
- 事务没提交就关闭数据库时，那次写入全部丢掉，已经提交的还在。

还没有把索引接到侧栏和日历上。文件监视的决定已经有了：没有未保存修改就更新，有冲突就停下来问。

# 7.20.0

小版本。便签可以用调色板自己选颜色，也可以自己定透明度。

上一版是 7.19.0。分叉基线仍然是上游 MarkText v0.20.0。

这次改了：

- 原来的六种底色还在，旁边多了一个取色器，可以选任意颜色。
- 透明度从 10% 到 100%，滑条旁边写着当前百分比。默认仍是不透明。
- 颜色和透明度只记在本机的便签状态里，不写进笔记。系统不支持变淡时，滑条会停用并说明。

Windows x64 安装包是 dist/marktext-win-x64-7.20.0-setup.exe。解包程序和安装包的文件版本都是 7.20.0。macOS 和 Linux 没有打包。

# 7.3.4

修订号。贴出便签时，主进程不再因为没有菜单而崩掉。

上一版是 7.3.3。分叉基线仍然是上游 MarkText v0.20.0。

7.3.3 让「贴到桌面」可以点到。点下去会开一个没有完整菜单的窗口，接着更新侧栏菜单时读到空菜单，整个程序弹出错误。

这次改了：

- 窗口没有对应菜单项时，跳过侧栏、格式、选区和布局的菜单更新。

窗口手测：打开文件夹后出现第二个窗口，标题是 milk.md - 桌笺。关掉主窗口后，这个窗口还在，进程也还在。状态文件记下它钉住，位置是 80,80。这个小窗口的截图是黑的，正文没有看清。没有再弹出 7.3.3 的菜单错误。

这台机器生成了 dist/marktext-win-x64-7.3.4-setup.exe。解包程序文件版本是 7.3.4。macOS 和 Linux 安装包没有生成。

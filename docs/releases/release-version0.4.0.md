# 0.4.0

小版本。探针 B 是第二扇不透明、无边框、置顶的窗口，复用现在的编辑器，不另写一套渲染。

基线仍是 MarkText v0.20.0。上一版是 0.3.0。

设置环境变量 DESKMARK_PROBE_B=1 后启动，主窗口旁边会再开一扇小窗。侧栏隐藏。拖动或改变大小时，矩形写到应用数据目录的 probe-b-bounds.json。下次启动，屏幕还在就恢复；屏幕不在就放到主显示器里。

矩形恢复有单元测试。这次只在 Windows 上写了代码，没有在 macOS、Ubuntu X11 和 GNOME Wayland 上打开这扇窗。Wayland 的置顶仍然不作为通过条件。

# 2.1.0

小版本。打开的文件在退出后还能回来，包括没保存过的新文件。快照不写回原来的文件。

上一版是 2.0.0。

这次做了：

- 应用数据目录里的 `open-session/session.json` 记下顺序、当前文件和光标。还没写回磁盘的内容放在 `open-session/backup/`。
- 大约每 7 秒写一次，退出前再写一次。写入用临时文件替换。
- 退出时不再逐个询问要不要保存，也不会把草稿写回原来的路径。
- 关掉其中一个文件后，它的缓存被删掉，下次不会再出现。
- 左侧已打开的文件可以上下拖动，顺序和标签是同一份。
- `.txt` 打开时用源码模式，`.md` 用即时模式。

强杀之后能否恢复，取决于最近一次快照。这一版没有在三台系统上做手测。

# 7.3.6

修订号。未保存的新文件在退出时会把刚打的字记进快照。

上一版是 7.3.5。分叉基线仍然是上游 MarkText v0.20.0。

7.3.5 上手测：新建 Untitled-1，输入「未保存手测735」，不保存就退出。会话把它标成未保存，但备份文件是空的。编辑器里的字还没写进状态，快照就读走了。原来的 milk.md 没有被改写。

这次改了：

- 记快照之前先把当前编辑器里的内容刷进状态。退出和每 7 秒的快照都走这一步。

窗口手测：新建 Untitled-1，输入「未保存手测736」，不保存就退出。再次打开后，这句话还在，标签仍标成未保存。没有写到任何笔记文件里。

这台机器生成了 dist/marktext-win-x64-7.3.6-setup.exe。解包程序文件版本是 7.3.6。macOS 和 Linux 安装包没有生成。

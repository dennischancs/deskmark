# 7.7.12

修订。打开一个有十几万个文件的文件夹时，待办索引改到单独的线程里走，窗口保持能点、能打字。

上一版是 7.7.11。分叉基线仍然是上游 MarkText v0.20.0。

这次改了：

- 递归、读纯文本、抽出待办都在后台线程。结果一小批一小批写进 `.deskmark`。没改过修改时间的文件不再读内容。
- 待办列表上的数字是已经点过的名字个数，不只是纯文本，所以大量图片时也能看到它在往前走。
- 侧栏不再为了列出文件把每一篇都读进内存，文件夹事件也分批送进界面。`.git` 和 `.deskmark` 不进入侧栏。

扩展名和识别规则仍在「设置 - 桌笺」里勾选或输入。原则写在 README。

没有做安装包。

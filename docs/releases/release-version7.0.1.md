# 7.0.1

修订。字数这个小功能改到自己的页面里跑，不再和正在写的笔记挤在一起。

上一版是 7.0.0。分叉基线仍然是上游 MarkText v0.20.0。

这次改了：

- 小功能的页面没有 Node，也不能改编辑器。它发出的请求带编号，由主程序核对清单里的允许项。
- 它只能读当前笔记。笔记文件夹外面的路径会被拒绝。
- 这个页面卡住或转个不停时，当前笔记仍然可以保存。
- 关于页写明：添加的小功能在这个程序里面运行，不是另一个单独的程序。
- 勾选带注释的待办后，注释还在。这条有桌面测试。

没有新增功能。这台机器生成了 dist/release-7.0.1/marktext-win-x64-7.0.1-setup.exe。macOS 和 Linux 安装包仍然不能在这里生成。

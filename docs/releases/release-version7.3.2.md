# 7.3.2

修订号。带着笔记文件夹再次打开时，上次还开着的文件会回来。

上一版是 7.3.1。分叉基线仍然是上游 MarkText v0.20.0。

7.3.1 只挡住了「还没恢复就写入」。窗口手测里，退出时会话确实记下了 milk.md。再次用同一个文件夹启动时，程序把已经保存的标签清掉，又写了一份空会话，所以打开的文件还是空的。

这次改了：

- 启动参数只是文件夹时，如果上次的窗口就是这个文件夹，就恢复那个窗口，不再把它当成一次新的空白启动。
- 从文件管理器打开单个文件时，仍然不把所有旧窗口一起拉起来。
- 这个进程里还没有出现过标签时，空快照不能盖掉已经有文件的会话。用户自己关掉全部文件之后，仍然会记成空的。

窗口手测：打开 notes/milk.md，退出，再用同一个文件夹启动。窗口标题是 milk.md - hand-731 - 桌笺，已打开的文件里还有这一篇，正文还在。7.3.1 上这一步失败。

这台机器生成了 dist/marktext-win-x64-7.3.2-setup.exe。解包程序文件版本是 7.3.2。macOS 和 Linux 安装包没有生成。

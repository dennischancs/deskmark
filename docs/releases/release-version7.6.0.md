# 7.6.0

小版本。待办栏可以搜索、排序，并在这一行里改待办。

上一版是 7.5.6。分叉基线仍然是上游 MarkText v0.20.0。

这次改了：

- 待办列表顶部有搜索框。没有符合的待办时会说明。
- 可以按优先级、日期或标题排序。当前用的那一种会用主题色标出来。
- 点一条待办，就在这一行里改文字、日期、提醒、优先级和重复，保存后写回原来的笔记。
- 「在笔记里打开」才跳到那一行。「在日历看」仍打开那一天。
- 待办栏开着的时候，窗口右边不再另放一块重复的属性栏。

没有做：把待办拖成一份自定义顺序。一条待办住在某一篇笔记里，列表只按优先级、日期或标题排。日历上仍可以把一条拖到另一天。

没有做安装包。

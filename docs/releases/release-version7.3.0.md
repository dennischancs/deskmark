# 7.3.0

小版本。待办和日历还是同一条原文，只是能从一边把日期写回去。

上一版是 7.2.4。分叉基线仍然是上游 MarkText v0.20.0。

参考了四套做法，没有照搬代码。

- Org 的 agenda：过了日期还没做完的，继续出现在今天，直到勾掉。快到截止日期的，提前几天在今天提一句。任务不从原文件搬出来。
- Logseq 的日记：别的笔记里的待办按日期出现，不抄进日记。
- Obsidian Tasks 配日历：没定日期的待办放在旁边。放到某一天时，把日期写回原来那一行。
- Vikunja：同一组里高优先级在前。没有拿它的看板和甘特图。

没有把「计划做」和「截止」拆成两个日期。文件里仍然只有一个 due。也没有周视图、拖到时间栅格、CalDAV。

这次改了：

- 选中某一天时，下面仍是这一天真正到期的待办。今天另外列出还没做完的（日期早于今天），以及接下来 3 天会到期的。再往下是还没定日期的。
- 「放到这天」把截止日期改成选中的那一天。原来有钟点的，钟点还在。行还在原来的笔记里，不会复制进日记。
- 「去掉日期」把这一行送回未定日期。
- 「去这天」只是跳到那条待办的日期，不改文件。
- 待办侧栏里，有日期的可以「在日历看」，日历打开到那一天。
- 同一组按高、普通、低排。带钟点的排在全天之前。
- 十二种语言都写了这些句子。设置里的说明也写了：放到某一天不会离开原笔记。

没有做安装包。核心测试 17 条通过，索引测试 8 条通过。

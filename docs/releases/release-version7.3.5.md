# 7.3.5

修订号。便签里的正文不再被右边的空属性栏挤窄。

上一版是 7.3.4。分叉基线仍然是上游 MarkText v0.20.0。

7.3.4 的便签窗口能打开，标题是笔记名。正文在左边，右边还有一块 240 像素的空属性栏，小窗口里看起来像半边是黑的。

这次改了：

- 便签窗口不再显示待办属性栏。属性栏仍留在主窗口。

窗口手测：便签标题是 milk.md - 桌笺。能看见「钉住」、六个颜色，以及正文「手测」、买牛奶、还没定日期。右边仍有一块深色空白，但正文不再被挡住。

这台机器生成了 dist/marktext-win-x64-7.3.5-setup.exe。解包程序文件版本是 7.3.5。macOS 和 Linux 安装包没有生成。

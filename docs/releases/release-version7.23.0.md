# 7.23.0

小版本。便签菜单补上图里其余的窗口动作。

上一版是 7.22.0。分叉基线仍然是上游 MarkText v0.20.0。

这次改了：

- 便签工具栏上的「菜单」可以打开便签设置、置顶、贴边隐藏，也可以关掉这张便签。
- 「锁定」里面有桌面锁定、鼠标穿透和置底。桌面锁定后不能再拖，也不能改大小。鼠标穿透时，点便签正文会落到下面的窗口，点标题栏和工具栏仍然能操作。置底会把便签放到普通窗口后面；置顶和置底不能同时开。
- 「其他便签」列出已经打开的另外几张，点一下就切过去。
- 这些开关只记在本机的便签状态里，不写进笔记。

这次还没有打 Windows 安装包。macOS 和 Linux 也没有打包。

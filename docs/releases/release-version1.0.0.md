# 1.0.0

大版本。阶段 1 的任务模型落地。解析、写回、重复和查询都不碰磁盘，也不启动 Electron。

上一版是 0.5.0。基线仍是 MarkText v0.20.0。

这次做了：

- 笔记级字段放在 front matter 的 deskmark 下面。不认识的键原样保留。front matter 没写完时，正文里的待办仍然能读。
- 行内待办仍是 `- [ ]`。只有设置了需要记住的字段，才在行尾写 deskmark 注释。
- 每天、每周、每月。没有截止日期不能重复。每月 31 日推进到下个月时，截到那个月的最后一天。
- 行内任务完成后留下原来的一行，并在下一行插入下一次，用新的 id。提醒和截止日期的间隔不变。
- 整篇待办笔记完成后仍保持打开，把截止日期推进，并在「完成记录」下追加一条。
- 已经是 RRULE 或其他不认识的重复规则时，原样保留，完成时不自动推进。
- 日历分组按本地时区。只有日期的事项过了当天才算逾期。带时间的事项过了那个时刻才算逾期。
- 从日历新建的文本落在 `journal/YYYY-MM-DD.md` 的一行里。

还没有索引、待办侧栏、便签产品和日历界面。探针 A 已经说明现有引擎不会丢掉这些注释，所以这一版没有改 `packages/muya`。

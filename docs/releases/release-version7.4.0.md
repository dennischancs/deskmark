# 7.4.0

小版本。待办和日历还是同一条原文、同一个截止日期，只是月历上能看见这些待办，也能把它们挪到另一天。

上一版是 7.3.7。分叉基线仍然是上游 MarkText v0.20.0。

参考了这些做法，没有照搬代码。

- Super Productivity（MIT）的 Planner，以及 Schedule 的月视图：同一批待办画在日期格子里。拖到另一天，截止日期跟着改。打开后面的某一天时，更早没做完的还在旁边，可以挪过去。没有采用它的周视图时间栅格，也没有接外部日历。
- Org agenda 的 log mode：一件事在哪一天被标成完成，就出现在那一天。这和截止日期不是一回事。没有把 SCHEDULED 和 DEADLINE 拆成两个日期。
- Tasks.org（GPL-3.0）把完成日期和截止日期分开保存。这里用文件里已经有的 completed，不新加字段。
- Vikunja（AGPL-3.0）官方目前是列表、看板、表格和甘特。月历还在它的愿望清单里，没有拿来当现成界面。借的是同一批任务、截止日期就是日历上的那一天。不借它的开始日和结束日，避免一条任务占两个格子。
- Logseq 的文件版：原文留在原来的笔记里，不抄进日记。

没有把「计划做」和「截止」拆开。文件里仍然只有一个 due。一条未完成的待办只出现在截止日期那一格。

这次改了：

- 月历格子里写出还没做完的待办。一格最多两行，再多就显示还剩几条。逾期的格子用删除色。已经做完的不占格子。
- 从格子、当天列表或待办侧栏拖到另一天，只改原来那一行的日期。原来有钟点的，钟点还在。整篇待办笔记没有行号，不能拖。
- 选中任意一天，不只是今天，都能把更早还没做完的放到这一天。
- 完成时间落在这一天、但截止日期是别的日子的，列在「这一天完成的」。截止日期本来就是这一天的，仍留在当天列表里，不重复列一次。
- 设置里这组开关的说明改成了上面这件事。开关仍在设置和视图菜单里。

没有做周视图、时间栅格、重复任务在未来每一天的预告、CalDAV。十二种语言都写了新句子。

桌面单元测试 982 项通过，36 项因平台跳过。核心测试 23 条通过，索引测试 9 条通过。

Windows 安装包是 dist/marktext-win-x64-7.4.0-setup.exe。解包程序文件版本是 7.4.0。

窗口手测：深色主题下，从视图、桌笺、打开日历进去。2026 年 10 月的月历字是主题色，不是黑字。7 日的格子里写着「买牛奶」，右边今天是 1，这条来自 milk.md，优先级是高。拖到另一天这一步还没有在窗口里做。

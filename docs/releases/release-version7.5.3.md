# 7.5.3

修订。到点提醒在没有安装过的程序里也能向 Windows 登记，通知上写笔记名和钟点。

上一版是 7.5.2。分叉基线仍然是上游 MarkText v0.20.0。

7.3.6 的手测里，提醒状态已经记成到点通知，但窗口列表里没有系统通知。Windows 会把没有开始菜单快捷方式的通知藏起来。安装包自己会写那条快捷方式。直接打开未打包的程序时，现在补写一条，开发运行用另一条，不替换已经安装的「桌笺」。

通知正文不再是一串原始时间，而是笔记名和钟点，例如 `milk.md / 09:05`。

Windows 安装包是 dist/marktext-win-x64-7.5.3-setup.exe。解包程序文件版本是 7.5.3。7.5.4 接着改了快捷方式的判断，通知弹层仍然没在窗口里看见。

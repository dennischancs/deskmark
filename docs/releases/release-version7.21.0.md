# 7.21.0

小版本。便签里可以打开一块调色板，自己选颜色，也可以自己定透明度。

上一版是 7.20.1。分叉基线仍然是上游 MarkText v0.20.0。

这次改了：

- 原来的六种底色还在。旁边的「调色板」打开后，可以在色板上取任意颜色，也可以直接填色值。
- 透明度从 10% 到 100%，和颜色在同一块板上，旁边写着当前百分比。默认仍是不透明。
- 调色板的字、边框和底色跟着当前 Markdown 主题走，不再用一套看不清的系统取色器。
- 颜色和透明度只记在本机的便签状态里，不写进笔记。系统不支持变淡时，滑条会停用并说明。

这次还没有打 Windows 安装包。macOS 和 Linux 也没有打包。

# 7.0.0

大版本。阶段 7 的候选版。日历、待办、便签和字数这些新句子，十二种界面语言都能读到。

上一版是 6.0.0。分叉基线仍然是上游 MarkText v0.20.0。

这次做了：

- 斜杠菜单里的待办、日期、提醒、今天、明天和日记，补进了其余十个编辑器语言。分组名用各语言的产品显示名，不把内部标识显示出来。
- 日历、便签和字数的新句子在十二个界面语言里都有。关掉小功能的按钮也跟着语言走。
- 德语、法语、俄语、日语的日历按钮都很短。界面不写保险库、宿主、SDK。上游设置里原来的 front matter 字样没有改。
- 手测清单在 qa/v1-matrix.md。能自动验的已经写明。窗口、托盘和系统通知还没有在这台机器上手测。
- 这台 Windows 机器生成了 dist/marktext-win-x64-7.0.0-setup.exe 和同版本的 zip。macOS 和 Linux 的安装包这里做不了。

还要知道的事：

- 在 Wayland 上，便签可能没法一直留在最前面。窗口里会说明。
- macOS 安装包还没生成，所以也还没签名。
- 提醒只在程序开着的时候发出。关掉之后，到点不会响。
- @ 随这一版交付。它复用斜杠菜单，邮箱中间的 @ 不会打开。
- 小功能跑在应用里的沙箱页面，不是单独的进程。开放商店之前要再隔离一次。

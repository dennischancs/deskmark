# 7.5.0

小版本。待办栏可以搜、换一种排法，也可以改原来那句话。

上一版是 7.4.1。分叉基线仍然是上游 MarkText v0.20.0。

这不是 Microsoft To Do 或滴答清单。没有清单、没有自己拖出来的顺序，也没有在待办栏里写长备注。待办仍然是笔记里的一行。

这次改了：

- 待办栏上面有一个搜索框。按这句话或文件名过滤，分组还是原来的逾期、今天、未来 7 天、更晚、无日期、已完成。
- 排序可以换成按优先级、按日期或按标题。默认仍是高优先级在前。按标题时，英文字母在前，中文在后。
- 点开一条之后，右边可以改这句话。保存后只改原来那一行，日期和优先级还在。

没有做安装包。核心测试通过，十二种语言的键对齐。

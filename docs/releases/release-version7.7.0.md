# 7.7.0

小版本。打开一个文件夹时，按设置里的纯文本扩展名和识别规则，在后台建立待办索引。

上一版是 7.6.3。分叉基线仍然是上游 MarkText v0.20.0。

这次改了：

- 默认会看编辑器本来就能打开的纯文本，包括 `.md` 和 `.txt`。设置里可以勾选，也可以自己输入扩展名。
- 识别规则写进 README，也可以在「设置 - 桌笺」里开关：任务行、行尾注释、文首 `kind: todo`、正文里的 `YYYY-MM-DD`，以及额外的行开头。
- 文件很多时不再一次读完。后台分批查看，没改过修改时间的文件不再读内容。待办列表显示已经看到多少个。超过 2MB 的单个文件跳过。

待办和日期仍写在原来的文件里。`.deskmark` 里的索引可以删掉再长出来。

没有做安装包。

# 7.5.4

修订。开始菜单里那条「桌笺」快捷方式如果没有应用编号，启动时补上。

上一版是 7.5.3。分叉基线仍然是上游 MarkText v0.20.0。

这台机器上已经有一条快捷方式，指向未打包的程序，但里面没有 `app.deskmark.desktop`。7.5.3 看到文件在就不再写。Windows 仍然不会弹出通知。现在只有带上这个编号的快捷方式才算已经登记。

Windows 安装包是 dist/marktext-win-x64-7.5.4-setup.exe。解包程序文件版本是 7.5.4。这台机器开始菜单里的「桌笺」快捷方式已经带有 `app.deskmark.desktop`。通知弹层还没在窗口里看见。

# 5.0.0

大版本。阶段 5 的日历和提醒可以用了。不用先打开编辑器，也能看到一个月，以及某一天的待办。

上一版是 4.0.0。分叉基线仍然是上游 MarkText v0.20.0。

这次做了：

- 侧栏可以打开月历。有截止日期的日子会标出来，一周从周一开始。点某一天能看到当天的待办，再点一条会打开原来的笔记并落到那一行。
- 在某一天新建一行，会写进 `journal/YYYY-MM-DD.md`。写完打开这一行。
- 笔记里输入 `/` 可以插入待办、今天、明天、提醒和日记链接。`@` 可以提到今天、明天、日记，以及当前文件夹里的其他笔记。邮箱里的 `@` 不会打开这个菜单。
- 用 `/` 或 `@` 写在当前笔记里的待办，仍留在这篇笔记，并出现在对应日期上。
- 提醒到点后一分钟内单独通知。更早错过的，每个本地日只汇总一次。点开刚到点的通知，会打开那篇笔记的对应行。

这次没有做日历订阅，也没有做插件。macOS 和 Linux 上没有实际弹出系统通知。

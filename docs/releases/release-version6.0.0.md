# 6.0.0

大版本。阶段 6 可以添加一个本地小功能，也可以关掉它。

上一版是 5.0.0。分叉基线仍然是上游 MarkText v0.20.0。

这次做了：

- 待办、日历和便签登记在同一张命令和视图表里。它们是内置功能，不进第三方页面。
- 字数示例放在 `plugins/sample-wordcount`。它只有一份清单和一个页面，不引用桌面或编辑器内部路径。
- 这个页面在沙箱里打开：没有 Node，也不能碰应用自己的界面。它只能读取当前笔记，用来数字数。
- 清单损坏、接口主版本不是 1、或者调用了没有声明的写入，都会被拒绝。关掉之后，命令和侧栏入口一起消失。
- 小功能如果超过时限，就停在它自己的调用上，不挡住当前笔记保存。

当前隔离是应用里的沙箱页面，不是单独的进程。开放插件商店之前要再升级隔离。这次没有做插件商店、签名或自动更新。

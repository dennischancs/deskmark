# 7.24.2

修订号。在 Mac Mini M4 上把编译和桌笺窗口测试跑通，并修了便签在这台机器上打不开正文的问题。

上一版是 7.24.1。分叉基线仍然是上游 MarkText v0.20.0。

这次改了：

- 窗口要等渲染进程登记好监听，再发送启动数据和笔记。否则笔记消息会丢，便签只剩工具条。
- 便签没有编辑菜单。macOS 上再改格式菜单或视图菜单时，缺的项目直接跳过，不再抛错。
- 补上桌笺索引包在锁文件里的依赖。
- 窗口测试打开便签时按当前系统拼接路径，结束进程时会把子进程一起关掉。

macOS arm64 安装包是 dist/deskmark-mac-arm64-7.24.2.dmg，另有同名的 zip。安装包没有 Apple 签名。拖进「应用程序」之后需要执行一次：

```
xattr -cr /Applications/Deskmark.app
```

Windows 和 Linux 安装包没有在这台机器上重新打。

# 7.1.0

小版本。新加的日历、待办、属性、便签条和字数跟着当前主题走。这些功能的开关在设置和视图菜单里。

上一版是 7.0.2。分叉基线仍然是上游 MarkText v0.20.0。

这次改了：

- 新界面不再自己写死黑字。文字、底色和按钮用主题里已经有的颜色。主题只要提供编辑区背景色，日期这类系统控件就会跟着变亮或变暗。现有 32 套主题都有这个颜色，所以不用给每一套再抄一份。
- 设置里增加一组开关：日历、待办、到点提醒、字数。每条待办自己的日期和提醒仍在待办旁边的属性里改。
- 视图菜单可以打开日历、待办和字数，把当前笔记贴到桌面，也可以开关这些功能，并直接打开这组设置。
- 关掉之后，侧栏不再显示对应入口。关掉提醒后，到点不再通知。缺省仍是打开。
- 十二种语言都写了这些句子。

没有做安装包。已经装上的 7.0.1 程序看不到这次界面。菜单模板测试 28 条通过。

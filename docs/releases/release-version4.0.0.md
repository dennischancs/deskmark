# 4.0.0

大版本。阶段 4 的便签可以贴出来。同一篇笔记只有一扇窗，关掉便签不删笔记。

上一版是 3.0.0。颜色和位置写在笔记文件夹的 `.deskmark/ui-state.json`，不写进 Markdown。

这次做了：

- 当前笔记可以贴到桌面。再贴一次只是把原来那扇窗拿到前面。
- 可以钉住，也可以换六种底色。拖动后的位置会记住，屏幕还在就恢复。
- 托盘能新建一条、显示主窗口、退出。有托盘时，关掉主窗口不会结束程序，便签还在。没有托盘时，关掉主窗口会退出，避免进程藏起来。
- 在 Wayland 上，便签里会说明它可能没法一直留在最前面。
- 登录时打开可以开关。它只负责下次把窗口带回来。

这次没有在 macOS 和 Linux 上实际打开窗口。日历、提醒和插件还没有做。

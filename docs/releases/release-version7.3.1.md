# 7.3.1

修订号。退出后再打开，上次还开着的文件不再被一次空快照清掉。

上一版是 7.3.0。分叉基线仍然是上游 MarkText v0.20.0。

启动时会先记下侧栏布局，再去读上次的文件。这一下如果抢在文件恢复之前写盘，会话和编辑缓冲都会变成空标签页。文件夹还在，打开的文件没了。

这次改了：

- 文件还没恢复之前，不把空的标签页写进会话。
- 恢复完成之后，才开始记快照。用户自己关掉全部文件，仍然会记成空的。
- 主进程再挡一次：没标成已经恢复的空快照，不能盖掉已经有文件的会话。

桌面单元测试 982 项通过，36 项因平台跳过，0 项失败。这一项还没在窗口里再手测。

这台机器生成了 dist/marktext-win-x64-7.3.1-setup.exe。解包后的程序文件版本是 7.3.1，能启动并跟系统语言。macOS 和 Linux 安装包没有生成。
